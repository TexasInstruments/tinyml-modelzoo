# ECG Classification



  ## How to Run

  After completing the repository setup, run the following command from the `tinyml-modelzoo` directory:

  **Windows:**
  ```bash
  .\run_tinyml_modelzoo.bat examples\ecg_classification\<config_file>
```
**Linux:**
  ```bash
  ./run_tinyml_modelzoo.sh examples/ecg_classification/<config_file>
```
 ## Available Default Configurations For Each Device Family

 
  - config.yaml - AM13E2
  - config_MSPM0.yaml - MSPM0G5187
